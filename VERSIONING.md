# SynoCommerce Semantic Versioning Policy

SynoCommerce strictly adheres to [Semantic Versioning 2.0.0](https://semver.org/):

- **MAJOR (X.0.0)**: Breaking API contract changes or architectural revisions.
- **MINOR (0.X.0)**: New backwards-compatible modules, engines, or feature additions.
- **PATCH (0.0.X)**: Backwards-compatible bug fixes and security hardening.
