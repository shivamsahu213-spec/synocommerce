# FedEx International & Domestic Shipping Integration

## Overview

FedEx Web Services integration for domestic and cross-border express parcel delivery.

---

## Configuration

Set environment variables in `.env.production`:

```env
FEDEX_API_KEY=fedex_prod_key
FEDEX_SECRET_KEY=fedex_prod_secret
FEDEX_ACCOUNT_NUMBER=fedex_prod_acc
```
