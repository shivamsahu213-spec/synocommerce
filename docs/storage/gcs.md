# Google Cloud Storage (GCS) Integration

## Overview

Google Cloud Storage (GCS) integration for high-availability enterprise media hosting.

---

## Configuration

Set environment variables in `.env.production`:

```env
GCS_BUCKET=syno-prod-gcs
GCS_CLIENT_EMAIL=prod@synocommerce.iam.gserviceaccount.com
GCS_PRIVATE_KEY=prod_private_key
```
