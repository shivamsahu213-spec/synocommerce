# MinIO Self-Hosted Object Storage Integration

## Overview

MinIO high-performance S3-compatible self-hosted object storage integration for on-premises deployments.

---

## Configuration

Set environment variables in `.env.production`:

```env
MINIO_ENDPOINT=minio.internal.synocommerce.com
MINIO_PORT=9000
MINIO_ACCESS_KEY=minioprodadmin
MINIO_SECRET_KEY=minioprodsecret
```
