# Cloudinary Media Storage & Transformation Integration

## Overview

SynoCommerce integrates with Cloudinary for dynamic image transformations, automatic WebP/AVIF formatting, and video transcoding.

---

## Configuration

Set environment variables in `.env.production`:

```env
CLOUDINARY_CLOUD_NAME=syno-prod
CLOUDINARY_API_KEY=prod_key
CLOUDINARY_API_SECRET=prod_secret
```
