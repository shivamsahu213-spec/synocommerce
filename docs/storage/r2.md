# Cloudflare R2 Zero-Egress Storage Integration

## Overview

SynoCommerce uses Cloudflare R2 for zero-egress cost object storage across global edge data centers.

---

## Configuration

Set environment variables in `.env.production`:

```env
CLOUDFLARE_R2_ACCOUNT_ID=cf_prod_account
CLOUDFLARE_R2_ACCESS_KEY_ID=cf_prod_key
CLOUDFLARE_R2_SECRET_ACCESS_KEY=cf_prod_secret
```
