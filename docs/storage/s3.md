# Amazon S3 Object Storage Integration

## Overview

SynoCommerce integrates with Amazon S3 for durable, high-throughput cloud asset storage.

---

## Configuration

Set environment variables in `.env.production`:

```env
AWS_S3_BUCKET=syno-prod-media-us-east-1
AWS_S3_REGION=us-east-1
AWS_S3_ACCESS_KEY_ID=s3_prod_key
AWS_S3_SECRET_ACCESS_KEY=s3_prod_secret
```

---

## API Usage

```typescript
import { ObjectStorageProvider } from '@/integrations/storage';

const storage = new ObjectStorageProvider();
const meta = await storage.uploadFile('image.png', 'image/png', buffer, {
  providerPreference: 'AWS_S3',
  folder: 'products',
});
```
