# Report Builder & Scheduled Export Engine

## Overview

Self-service custom report creation, filtering, aggregation, and export in CSV, Excel, and PDF formats, with automated email schedule dispatch.

---

## Supported Exports

- **CSV Export**: Raw tabular dataset export.
- **Excel Export**: Multi-tab formatted spreadsheet.
- **PDF Export**: Executive presentation printout.
- **Email Scheduling**: Standard cron expression dispatch (`0 8 1 * *`).
