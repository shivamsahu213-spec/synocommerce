# Datadog APM & Synthetic Monitoring Integration

## Overview

Datadog APM integration for distributed tracing, log management, and synthetic HTTP uptime monitoring.

---

## Configuration

Set environment variables in `.env.production`:

```env
DATADOG_API_KEY=dd_prod_key
DATADOG_APP_KEY=dd_prod_app_key
DATADOG_SITE=datadoghq.com
```
