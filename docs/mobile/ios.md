# iOS Mobile SDK (Swift)

## Overview

SynoCommerce iOS SDK provides Swift Package Manager (SPM) integration, Keychain Secure Enclave storage, and Apple Pay checkout integration.

---

## Installation (Swift Package Manager)

```swift
dependencies: [
    .package(url: "https://github.com/synocommerce/ios-sdk.git", from: "1.4.0")
]
```
