# Firebase (FCM) & Apple (APNs) Push Notifications

## Overview

Cross-platform push notification service supporting FCM v1 HTTP API, Apple APNs HTTP/2, and Web Push VAPID standards.

---

## Configuration

Set environment variables in `.env.production`:

```env
FCM_SERVER_KEY=fcm_prod_key
APNS_KEY_ID=apns_prod_key
APNS_TEAM_ID=apns_prod_team
```
