# Twilio SMS & OTP Integration

## Overview

Twilio Programmable SMS API integration for global order alerts and high-deliverability authentication OTPs.

---

## Configuration

Set environment variables in `.env.production`:

```env
TWILIO_ACCOUNT_SID=AC_prod_your_sid
TWILIO_AUTH_TOKEN=twilio_prod_token
TWILIO_PHONE_NUMBER=+18005550199
```
