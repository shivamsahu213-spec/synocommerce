# Multi-Language Notification Template Engine

## Overview

SynoCommerce features an MJML and Handlebars template engine supporting localized translations across 10+ languages.

---

## Supported Templates

- `ORDER_CONFIRMATION`
- `ORDER_SHIPPED`
- `ORDER_DELIVERED`
- `REFUND_CONFIRMATION`
- `PASSWORD_RESET`
- `EMAIL_VERIFICATION`
- `INVOICE`
- `ABANDONED_CART`
- `OTP`
- `MARKETING`
