# Migration Wizard & Supported Platform Connectors

## Overview

Step-by-step migration wizard for connecting, mapping, validating, and importing e-commerce store data.

---

## Supported Source Platforms (16 Connectors)

Shopify, WooCommerce, Magento 2, Adobe Commerce, BigCommerce, OpenCart, PrestaShop, Salesforce Commerce Cloud, SAP Commerce, CommerceTools, Vendure, Saleor, Medusa, Custom CSV, Custom JSON, Custom XML.
