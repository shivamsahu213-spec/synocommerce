# AWS OpenSearch Service Integration

## Overview

AWS OpenSearch integration for cloud-native managed search, security analytics, and k-NN vector search.

---

## Configuration

Set environment variables in `.env.production`:

```env
OPENSEARCH_NODE=https://opensearch-cluster.internal.synocommerce.com:9200
OPENSEARCH_USERNAME=syno_admin
OPENSEARCH_PASSWORD=opensearch_prod_pass
```
