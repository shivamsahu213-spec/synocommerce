# Algolia Hosted Search API Integration

## Overview

Algolia integration for cloud-hosted instant search UI widgets, AI recommendations, and rule-based merchandising.

---

## Configuration

Set environment variables in `.env.production`:

```env
ALGOLIA_APP_ID=algolia_prod_app_id
ALGOLIA_ADMIN_KEY=algolia_prod_admin_key
ALGOLIA_SEARCH_KEY=algolia_prod_search_key
```
