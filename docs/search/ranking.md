# Search Merchandising & Ranking Rules

## Overview

Merchandisers can override default relevance ranking with business rules, sponsored product boosts, and pinned product lists.

---

## Features

- **Pinned Products**: Pin high-margin SKUs to position #1 for specific query terms.
- **Boost Factors**: Multiply search scores by brand, category, or inventory level.
- **Synonyms**: Multi-term synonym mapping (e.g. `triphala = ayurvedic juice = herbal drink`).
