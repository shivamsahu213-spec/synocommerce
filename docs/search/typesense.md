# Typesense Open Source Search Integration

## Overview

Typesense integration for fast, in-memory open-source search with low RAM overhead and out-of-the-box typo tolerance.

---

## Configuration

Set environment variables in `.env.production`:

```env
TYPESENSE_HOST=typesense.internal.synocommerce.com
TYPESENSE_PORT=8108
TYPESENSE_API_KEY=typesense_prod_key
```
