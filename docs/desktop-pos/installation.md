# Desktop POS Installation & Setup Guide

## Overview

Installation instructions for Windows (.exe / .msi), macOS (.dmg / .app), and Linux (.deb / .AppImage).

---

## Build Commands

```bash
# Build Windows Installer
npm run build:desktop -- --win

# Build macOS Package
npm run build:desktop -- --mac

# Build Linux AppImage
npm run build:desktop -- --linux
```
