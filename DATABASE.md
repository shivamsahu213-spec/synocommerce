# Database

The frontend does not own database schema implementation, but it must align with backend domain boundaries.

## Planned Core Domains

- Products
- Categories
- Customers
- Addresses
- Carts
- Orders
- Payments
- Shipments
- Promotions
- Inventory

## Future Domains

- Vendors
- Subscriptions
- Companies and B2B accounts
- CMS content models
- Audit logs

## Frontend Expectations

- Stable identifiers across channels
- Explicit locale and currency support
- Price and inventory snapshots for transactional flows
